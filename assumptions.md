# Assumptions

Every physical assumption used anywhere in this repository is recorded here with its value, unit, justification and citation. Reports and docstrings cite entries by ID (e.g. `[A-03]`, `[B-07]`). A value in code that has no entry here is a bug. Entries marked `TBD(...)` are placeholders to be filled by the named group; citations marked "unverified" must be checked before the final report.

Table format: `| ID | Quantity | Value | Unit | Justification | Source |`

The sampled true bias is stored in `SensorData.gyro_bias`. **Coarse sun sensor.** The vendor figure is "< 5 deg (1-sigma) of sun determination accuracy" after calibration per the user manual, ±60° field of view per sensor, analog photodiode. It is interpreted as the 1σ (rms) total angle error of the reconstructed direction. Model: ideal cosine response `max(0, n_i · s)` on the lit faces, noise N(0, σ_d²) on all six diodes (also in eclipse), reconstructed vector `s_meas = I(+axis) − I(−axis)` (not normalised, equals the unit vector for noise-free lit input because `max(0,x) − max(0,−x) = x`). Each axis is the difference of two independent diode currents, so the per-axis noise is √2 σ_d. Only the two components perpendicular to s change the direction to first order, so the rms total angle error is √2 × (√2 σ_d) = 2 σ_d; setting this to 5 deg gives σ_d = 5 × (π/180) / 2 = 0.043633 (hand calculation; the code rounds to 0.0436). Check: √2 × 0.0436 = 0.06166 per axis, √2 × 0.0617 = 0.0872 rad = 5.0° (4.996° with 0.0616597; hand calculation). Validity: the summed current of a lit face set is the L1 norm of the unit sun vector, ≥ 1, and 0 in eclipse; noise on the sum has std √6 σ_d = 2.4495 × 0.0436 = 0.1068. Threshold 0.6 is therefore 0.6/0.1068 = 5.6 noise std above the eclipse mean (false detection) and (1 − 0.6)/0.1068 = 3.7 noise std below the lit minimum (miss) (hand calculation, Gaussian assumption; the threshold is a design choice). For the sensitivity cell with a 10° CSS the same calculation gives 2.8 and 1.9 std, see B-20.
